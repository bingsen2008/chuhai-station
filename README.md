# 出海实验站

短剧海外实验的业务流程模拟台。默认以一份《潮声》实验案件展示清晰的交接路径、角色、人工审批、实时模拟指标和交付物；五层等距楼宇保留为可切换的辅助视图。

**模拟数据 · 未连接真实业务。** 全部在浏览器内运行，无真实投放、消息、058 算力或其他外部 API，不需要登录、账号、密钥或凭证。

## 本地运行

```bash
npm install
npm run dev
```

打开 [http://127.0.0.1:4317/chuhai-station/](http://127.0.0.1:4317/chuhai-station/)。项目使用 Next.js 15 静态导出，默认 basePath `/chuhai-station`，构建产物为 `out/`；保留现有 `NEXT_PUBLIC_BASE_PATH` 配置能力及 GitHub Pages workflow。

## 一键开始

1. 点击“一键跑通”，任务包按事件沿有方向且带交接物说明的路径移动。
2. 到“用户审批”会暂停。阅读交付物后选择批准或退回；批准只继续本地演示。
3. 对账、选题反馈及知识卡片交付后，下一轮提纲回流策略，本轮停止。

可播放、暂停、单步，选择 0.5 / 1 / 2 / 4x，或完整重置。单步每次恰好一个事件；审批不能被播放或单步跳过。首次引导可跳过并随时重开。

三个场景：

| 场景 | 差异 |
| --- | --- |
| 正常闭环 | 准入 → 策略 → 人工审批 → 四批模拟样本 → 对账 → 选题反馈 → 下一轮策略 |
| 准入退回 | 字幕权利缺项 → 返工 → 材料 v2 再提交 → 继续主线 |
| 投放异常 | 第二批花费节奏异常 → 靓仔协调 → 用户决定继续观察或结束后对账 |

业务专家只做旁路规则咨询；靓仔总控协调；用户审批保留真正决策权。知识沉淀是闭环交付物，不是后台或定时任务。

## 数字与存储

固定 seed 20261107，纯函数引擎以离散 tick 推进，同一状态驱动节点、路径、指标、日志和交付物。金额为整数美分累计，显示 USD；曝光/点击单位为次。ROI 为（模拟归因毛收入 − 模拟花费）/ 模拟花费，非净现金回报，示例不构成真实效果承诺。

`chuhai-station.flow-simulation.v2` 保存带 schema version 的完整快照。恢复会重放历史并校验全部状态，默认暂停。旧分层演示只沿用引导偏好，缺少完整信息的进度明确复位；损坏或不兼容的数据整份复位并提示，不再部分恢复。

原草稿编辑、JSON 导入导出、名册与手动复制交接保留在页面末尾“原本地草稿工作台”，按需展开。草稿仍使用 `haichu-experiment-station.draft.v1`，与模拟案件独立；导入、清空草稿不会改变流程模拟状态。无跨设备同步。

## 验证

```bash
npm run lint
npm run typecheck
npm test
npm run build
node scripts/check-export.mjs
```

详见 [流程设计、存储协议、场景与验收说明](docs/flow-simulation.md)。覆盖引擎、存储迁移与恢复、播放/暂停/单步/调速/重置、场景/视图切换、人工审批及旧草稿回归。

手机采用纵向流程，状态同时使用文字、图标和颜色；当前节点与下一步滚动保留，日志使用 aria-live。支持键盘焦点、Esc 关闭原草稿浮层，以及减少动态效果偏好。

本次运行环境不能启动本地预览或 Chromium，真实浏览器的布局、位移动画与读屏通告仍需按验收说明手工复核。`docs/screenshots/` 保留原楼宇参考图。
